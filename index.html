How it works. Procreate files unzip with JSZip and expose a ready PNG — no decoding required. PSD uses ag-psd (reads the embedded composite). Modern .ai files are PDF-compatible, so the first page renders via pdf.js. The parser functions are DOM-free so they drop straight into a Chrome extension or a Drive "Open with" app.
